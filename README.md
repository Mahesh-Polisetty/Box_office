# 🎬 CinematicTrends: A Deep Dive into Box Office Analysis and Global Film Patterns
CinematicTrends is a comprehensive data visualization and analytics project that explores over six decades of global film industry data. From budget vs. revenue analysis to genre trends, production companies, and audience preferences, this project provides an interactive visual narrative designed to inform filmmakers, studios, and analysts.

---

## 📝 Abstract

This project analyzes global movie data from 1960 to 2018, revealing financial, cultural, and genre-related patterns. It provides studios and filmmakers with insights into profitable genres, production trends, critical vs. commercial success, and the geographic reach of cinema. The project uses both Python and Tableau for visualizations and builds an interactive web portal to democratize access to industry data.

---

## 🛠️ Tech Stack

Languages & Tools: Python, HTML, CSS, Bootstrap

Libraries: Pandas, NumPy, Matplotlib, Seaborn

Visualization Platforms: Tableau, Jupyter Notebook

Web Development: HTML/CSS with Tableau Dashboard Integration

---

## 📂 Dataset Information

Source: The Movies Dataset on Kaggle: https://www.kaggle.com/datasets/rounakbanik/the-movies-dataset

Duration Covered: 1960–2018

Records: ~45,000 movies

Key Attributes: Title, Budget, Revenue, Release Year, Genre, Language, Production Company, Country, Vote Rating, Popularity, Runtime

---

## 🎯 Project Goals

Identify high-performing genres and companies

Track the evolution of budgets, revenues, and audience preferences

Compare ratings vs. revenues to analyze critical vs. commercial hits

Build an interactive web-based dashboard using Tableau and Python plots

---

## 🔁 Workflow

1. Data Collection & Filtration:
Extract datasets from Kaggle, IMDB, Box Office Mojo. Clean JSON columns, remove invalid entries.

2. Data Visualization:
Use Python (matplotlib, seaborn) and Tableau to generate 20+ visualizations including stacked bars, treemaps, line charts, and choropleth maps.

3. Dashboard Creation:
Build interactive dashboards using Tableau, integrated into a website built with HTML, CSS, and Bootstrap.

---

## 📊 Key Visualizations & Insights

Budget vs Language: English-language films dominate budget allocation.

Budget/Revenue Over Time: Steady increase with recent volatility.

Top Companies: Disney, DreamWorks, and Universal lead in revenue.

Genre Trends: Drama, Comedy, and Action remain consistent leaders.

Critical vs Commercial Success: Highly rated films aren’t always highest grossing.

Choropleth Maps: Show geographic disparities in investment and revenue.

Network Graphs: Connect top genres to leading production companies.

Treemaps: Reveal budget and popularity distribution across genres.
